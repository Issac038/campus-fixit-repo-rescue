## Picking up an issue

1. Browse the [open issues](https://github.com/Issac038/campus-fixit-repo-rescue/issues) and choose an unassigned item.
2. Comment that you are working on it; ask for clarification there if the scope is unclear.
3. Create a branch from `main`, make the smallest complete change, and run `npm ci` and `npm test`.
4. Open a pull request that links the issue and summarizes the changes and verification.
